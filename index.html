Why nobody notices

The trigger is an ordinary value

The attacker does not invent a strange signal. It picks a signal strength that sits comfortably inside the range of perfectly normal, authentic readings — so there is no outlier for anyone to find.

The mechanism

The coordinator sets its own exam

It takes a signal it already knows is spoofed and makes one copy per feature, each with a single value overwritten to look safe. Then it asks every drone's model the same question. An honest model still says "spoofed" every time. A backdoored one slips on exactly one copy — and that is the giveaway.

The hardest question

What if the attacker knows about the exam?

We built one that does. It trains specifically to pass the coordinator's probes. Drag the dial: it does get better at hiding — and its backdoor falls apart as it does, even with no defense running at all.
